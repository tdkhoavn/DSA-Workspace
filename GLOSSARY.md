# DSA Workspace

A personal record of working through NeetCode's *Algorithms and Data Structures for Beginners* course in C++: lesson notes, problem solutions, and the C++ learned along the way.

## Language

### Course structure

**Course**:
NeetCode's *Algorithms and Data Structures for Beginners*, the curriculum this workspace follows.
_Avoid_: Class, tutorial

**Topic**:
One of the course's groupings of related Lessons, such as Arrays or Graphs.
_Avoid_: Chapter, section, module

**Lesson**:
One numbered page of the Course (0–34), consisting of a video and an article on a single concept.
_Avoid_: Lecture, video, article, unit

### Practice

**Problem**:
A coding task listed under a Lesson's suggested problems, identified by its LeetCode slug.
_Avoid_: Exercise, question, challenge, task

**Solution**:
The learner's own working code for a Problem, together with the tests that check it.
_Avoid_: Answer, submission

**Approach**:
The technique a Solution uses (e.g. two pointers, recursion, heap), stated with its time and space complexity.
_Avoid_: Method, strategy, idea

**Revisit**:
A Problem that appears under more than one Lesson; each appearance gets its own Solution using that Lesson's technique.
_Avoid_: Duplicate, repeat

### Notes

**Lesson Notes**:
The reviewed, corrected summary of a Lesson, written in Vietnamese in the learner's and Claude's own words.
_Avoid_: Summary, transcript, cheat sheet

**Playground**:
A runnable, untested program belonging to a Lesson, used to experiment with that Lesson's code.
_Avoid_: Sandbox, scratch, demo

**C++ Note**:
A short reference page on one C++ concept learned while solving Problems.
_Avoid_: C++ tip, snippet
